# 🚀 Complete Git & GitHub Guide

This guide takes you from **zero → practical Git usage** with all
essential commands in one place.

------------------------------------------------------------------------

# 📌 What is Git?

Git is a distributed version control system used to: - Track code
changes - Collaborate with teams - Manage project history

------------------------------------------------------------------------

# 📌 What is GitHub?

GitHub is a cloud platform to: - Host repositories - Collaborate via
pull requests - Showcase your projects

------------------------------------------------------------------------

# ⚙️ Installation & Setup

## Install Git

https://git-scm.com/downloads

## Verify Installation

``` bash
git --version
```

## Configure Git (IMPORTANT)

``` bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

Check config:

``` bash
git config --list
```

------------------------------------------------------------------------

# 📁 Repository Setup

## Initialize Repository

``` bash
git init
```

## Clone Existing Repository

``` bash
git clone https://github.com/user/repo.git
```

------------------------------------------------------------------------

# 🛠️ Basic Workflow

## Check Status

``` bash
git status
```

## Add Files

``` bash
git add file.txt
git add .
```

## Commit Changes

``` bash
git commit -m "Your message"
```

## View Changes

``` bash
git diff
```

------------------------------------------------------------------------

# 🔄 Undo & Fix Mistakes

## Unstage File

``` bash
git reset file.txt
```

## Discard Changes (DANGEROUS)

``` bash
git checkout -- file.txt
```

## Amend Last Commit

``` bash
git commit --amend -m "Updated message"
```

------------------------------------------------------------------------

# 🔍 History & Logs

``` bash
git log
git log --oneline
git log --graph
git show <commit_id>
```

------------------------------------------------------------------------

# 🌿 Branching

## Create Branch

``` bash
git branch feature
```

## List Branches

``` bash
git branch
```

## Switch Branch

``` bash
git checkout feature
```

## Create + Switch

``` bash
git checkout -b feature
```

## Rename Branch

``` bash
git branch -m new-name
```

## Delete Branch

``` bash
git branch -d feature
```

------------------------------------------------------------------------

# 🔀 Merging

``` bash
git checkout main
git merge feature
```

------------------------------------------------------------------------

# 🌐 Remote Repositories

## Add Remote

``` bash
git remote add origin https://github.com/user/repo.git
```

## View Remotes

``` bash
git remote -v
```

## Push Code

``` bash
git push -u origin main
```

## Push Branch

``` bash
git push origin feature
```

## Pull Changes

``` bash
git pull origin main
```

## Fetch Changes

``` bash
git fetch
```

------------------------------------------------------------------------

# 🔁 Stashing

``` bash
git stash
git stash list
git stash apply
git stash drop
```

------------------------------------------------------------------------

# ⚔️ Merge Conflicts

Resolve manually, then:

``` bash
git add file.txt
git commit
```

------------------------------------------------------------------------

# 🔄 Reset & Revert

## Soft Reset

``` bash
git reset --soft HEAD~1
```

## Hard Reset

``` bash
git reset --hard HEAD~1
```

## Revert

``` bash
git revert <commit_id>
```

------------------------------------------------------------------------

# 📦 Tags

``` bash
git tag v1.0
git tag
git push origin v1.0
```

# 🧠 Best Practices

-   Commit small changes
-   Use branches
-   Pull before push
-   Avoid secrets
-   Write clear messages

------------------------------------------------------------------------

# 🔥 Workflow Example

``` bash
git clone <repo-url>
cd repo
git checkout -b feature
git add .
git commit -m "feature"
git push origin feature
```
